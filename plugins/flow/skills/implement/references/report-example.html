Ticket 01 — export button and CSV builder

1.1 Column order and header

export/build-order-csv.ts:12, buildOrderCsv(rows, columns). The file follows what the user sees, not the API shape:

buildOrderCsv(rows, columns)
  visible = columns where !hidden, in the grid's current order
  header  = visible.map(label)                 (the translated label, not the field key)
  for each row
    cell = column.format ? column.format(row) : row[column.field]
    line = visible.map(cell → csvEscape(cell)).join(',')
  return [header, ...lines].join('\r\n')       (CRLF: spreadsheet apps expect it)
Needs review: the builder uses each column's display format, so amounts come out as the user sees them (1,250.00) and the file is not machine-numeric. The spec asks for "what the screen shows" (AC-003); the raw-number alternative was rejected in DEC-002.

Library — csvEscape

Why fields broke before

The old csvEscape quoted only fields with commas. A note containing a line break or a double quote split the row in two when opened in a spreadsheet.

Fix

-  return value.includes(',') ? `"${value}"` : value;
+  return /[",\r\n]/.test(value) ? `"${value.replaceAll('"', '""')}"` : value;

web-app gets the fix once lib-common is released and its version bumped; until then the local link carries it.
